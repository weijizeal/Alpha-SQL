9. **多概念查询（重要）**：
   - **禁止使用 LIKE '%%' + AND 组合**！
   - 例如：查询"同时属于概念A和概念B的股票"**不能用**：
     ```sql
     WHERE concept LIKE '%A%' AND concept LIKE '%B%'
     ```
   - **原因**：`concept` 列存储的是单个字符串值（如 "北斗导航,军工"），无法同时包含两个概念。这种写法只有在概念字段本身存储多个概念的组合时才能工作，但大多数情况下，每只股票只有一个概念值。
   - **正确做法**：使用 INTERSECT 或 UNION 来实现多概念筛选！
     - **INTERSECT 方式**：先查出属于概念A的股票，再查出属于概念B的股票，最后取交集
       ```sql
       SELECT `secucode` FROM `hq_basic_view` WHERE `concept` = '概念A'
       INTERSECT
       SELECT `secucode` FROM `hq_basic_view` WHERE `concept` = '概念B'
       ```
   - **举例**：假设有股票000001概念是"北斗导航"，股票000002概念是"军工"，股票000003概念是"北斗导航,军工"（极少）。查询"同时属于北斗导航和军工的股票"应该返回000003，而不是000001或000002。LIKE+AND只能匹配到000003这种组合概念，但实际需求通常是找分别属于两个概念的股票交集。
10. **日期处理（关键）- 使用 get_date() 函数）：**
    - **issue_list_date 等日期列是字符串类型**，使用前必须用 `toDate()` 转换为日期后再与 get_date() 结果比较！
    - **必须使用 get_date() 函数**来处理日期，不要直接写死日期字符串！
    - **禁止使用 STRFTIME、DATE、JULIANDAY 等 所有和SQLite有关函数！**
    - 函数格式：`get_date('日期字符串', is_start=布尔值, lookback_days=数字)`
    - **日期字符串格式**：
      - 绝对日期：`'yyyy-mm-dd'`（如 `'2024-01-01'`）
      - 相对日期：`'nX'` 格式（n=数值，X=单位）
        - `d` = 日：`'-20d'` = 20天前，`'0d'` = 今天，`'+1d'` = 明天
        - `m` = 月：`'-6m'` = 6个月前，`'0m'` = 本月1号，`'+1m'` = 下个月
        - `y` = 年：`'-1y'` = 一年前，`'0y'` = 今年1月1日
        - `q` = 财报季度：`'-1q'` = 上季度，`'0q'` = 本季度
        - `w` = 周：`'-1w'` = 一周前，`'0w'` = 本周一
      - 复合日期：`'2025y6m15d'` 或 `'6m15d'`
      - 特殊值：`'近期'` = 最近10天
    - **is_start 参数**：
      - `is_start=True` 表示日期范围的开始
      - `is_start=False` 表示日期范围的结束
    - **在 SQL 中的写法**（注意要用 toDate() 转换字符串日期列）：
      ```sql
      WHERE toDate(`hq_basic_view`.`issue_list_date`) >= get_date('2024-01-01', is_start=True)
        AND toDate(`hq_basic_view`.`issue_list_date`) <= get_date('2025-06-30')
      ```
    - **使用示例**：
      - "2024年至2025年6月"：`get_date('2024-01-01', is_start=True)` 和 `get_date('2025-06-30')`
      - "近20日"：`get_date('-20d', is_start=True)` 和 `get_date('0d')`
      - "半年内"：`get_date('-6m', is_start=True)` 和 `get_date('0d')`
      - "去年"：`get_date('-1y', is_start=True)` 和 `get_date('0y')`
    - **重要**：生成 SQL 时必须使用 get_date() 函数调用形式，不要写死日期字符串！
